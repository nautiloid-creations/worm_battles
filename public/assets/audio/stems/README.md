# Stems Audio Folder

Drop your default stem audio files into this directory with the following filenames:

- `guitar_1.mp3` (or `.wav`, `.ogg`, `.flac`)
- `guitar_2.mp3` (or `.wav`, `.ogg`, `.flac`)
- `bass.mp3` (or `.wav`, `.ogg`, `.flac`)
- `drums.mp3` (or `.wav`, `.ogg`, `.flac`)

When Worm Battles starts, any files matching these names will automatically preload into the Stem Player.
You can also load any custom audio file at any time using the **[ Load File ]** buttons in the Audio & Visualizer sidebar panel.

### Future Mixer Channel Mapping:
- Guitar 1: Channels 3 & 4 (Stereo)
- Guitar 2: Channels 5 & 6 (Stereo)
- Bass: Channel 7 (Mono)
- Drums: Channel 8 (Mono)
